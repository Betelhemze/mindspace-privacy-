# Mindspace Privacy Policy

**Last updated:** November 13, 2026

## 1. Introduction

Mindspace is a personal thought-capture and journaling extension for Microsoft Edge. It allows users to write, save, and manage personal thoughts, notes, and ideas while browsing the web.

Your privacy is important to us. This Privacy Policy explains how Mindspace handles information when you use the extension.

## 2. Information We Handle

Mindspace may process the following information:

**User-generated content**
- Thoughts and notes written by users.
- Unfinished drafts.
- Extension preferences and settings.

**Selected webpage text**
- If the user explicitly selects text on a webpage and chooses to save it through the Mindspace context menu, that selected text is processed as part of the user's saved entry.

Mindspace does not intentionally collect browsing history, location information, financial information, or personal identification information.

## 3. How Information Is Used

Information is used exclusively to provide the extension's journaling functionality, including:

- Creating and saving thoughts.
- Retrieving previously saved entries.
- Editing and deleting journal entries.
- Preserving drafts and extension preferences.
- Providing access to saved thoughts through the extension interface.

Mindspace does not use journal content for advertising or behavioral tracking.

## 4. Data Storage

Mindspace is designed to store journal entries locally in the user's browser using the browser's extension storage facilities.

In the current version:
- Journal entries are stored locally.
- The extension does not require an online account.
- Journal content is not intentionally transmitted to an external server.
- Data is not automatically synchronized with the Mindspace mobile application.

Users should understand that browser profile deletion, extension removal, or device failure may result in the loss of locally stored information.

## 5. Data Sharing

Mindspace does not sell, rent, or share users' journal entries with advertisers or other third parties.

The extension does not transmit journal content to external services as part of its intended local-only functionality.

## 6. Data Security

Mindspace uses browser-provided storage mechanisms and limits access to information to the extension's functionality.

Users should keep their devices and browser profiles secure.

Local browser storage should not be considered equivalent to an encrypted database or a secure backup. Users should avoid storing highly sensitive information unless appropriate additional protection is implemented.

## 7. User Control and Data Deletion

Users can manage their journal entries through the Mindspace extension.

Users may:
- View their saved thoughts.
- Edit existing entries.
- Delete individual entries.
- Remove locally stored extension data by using the available deletion functionality.

Removing the extension or clearing browser data may also remove locally stored journal information.

## 8. Children's Privacy

Mindspace is not specifically designed to collect personal information from children. The extension does not intentionally collect children's personal information.

This Privacy Policy may be updated when Mindspace introduces new functionality or changes how information is handled.

Any significant changes will be reflected in the updated policy published at this URL.
